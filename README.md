# N64 LEDs

Phone control page for the LEDs inside a clear N64 shell. Open in Chrome on Android, tap
Connect, pick **N64-LEDs**, and enter the board's pairing PIN the first time.

Uses Web Bluetooth, so it only works in Chromium-based browsers on Android, ChromeOS,
Windows, macOS and Linux (not iOS).

This repo is a publish target only. The source of truth lives in the private firmware
repo's `web/` folder; edits made here get overwritten.
